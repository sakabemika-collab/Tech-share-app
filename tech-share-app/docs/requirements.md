No. 機能 説明
1. 記事一覧： 投稿された記事をすべて表示する
2. 記事詳細： 1件の記事の内容を表示する
3. 記事投稿： 新しい記事を作成する
4. 記事編集： 既存の記事を修正する
5. 記事削除： 記事を削除する
6. 記事検索： タイトル・本文で絞り込む

■ Article（記事）のデータ項目 
フィールド 型 説明 例 
1 文字列 一意の識別子 "1" 
2 文字列 記事タイトル "React Hooksの完全理解" 
3 文字列 本文（Markdown） "## useStateとは..." 
4 文字列 投稿者名 "Tech Taro" 
5 文字列 作成日 "2026-05-14"

■ エンドポイント
一覧 メソッド URL 操作
GET /articles： 記事を全件取得
GET /articles/:id： 特定の記事を取得
POST /articles： 記事を新規作成
PATCH /articles/:id： 記事を更新
DELETE /articles/:id： 記事を削除
